# нейро.5 — AI-дайджест для новичков

Конверсионный сайт на Flask: тёмный дизайн, девять готовых материалов,
карточки с кнопкой «Открыть материал» и форма подписки.

## Запуск

```bash
# 1. Создайте виртуальное окружение (достаточно один раз)
python -m venv .venv

# 2. Активируйте его
# macOS / Linux:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate

# 3. Установите Flask
pip install -r requirements.txt

# 4. Запустите сайт
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

Если не хочется создавать окружение, можно установить Flask глобально:
`pip install -r requirements.txt`, а затем `python app.py`.

## Что уже готово

- Главная страница с hero-блоком, бегущей строкой, карточками, блоком «как учиться», подпиской и FAQ.
- 9 полноценных материалов с отдельными страницами.
- Кнопка «Открыть материал» на каждой карточке.
- Форма подписки с серверной проверкой email.
- Страница 404.
- Адаптивная вёрстка для телефона и компьютера.
- Плавные появления при скролле, подсветка карточек, прогресс чтения, мобильное меню.
- Уважение к `prefers-reduced-motion`.

## Как добавить материал

Откройте `materials.py` и добавьте в список `MATERIALS` новый словарь
по образцу существующих. Обязательные поля: `num`, `slug`, `title`,
`description`, `category`, `level`, `minutes`, `icon`, `accent`, `lead`,
`sections`, `takeaways`.

- `slug` — часть адреса: `/material/ваш-slug`.
- `accent` — цвет карточки, например `#d8ff4f`.
- `icon` — имя иконки из спрайта в `templates/base.html`
  (`sparkles`, `terminal`, `compass`, `alert`, `zap`, `palette`,
  `briefcase`, `shield`, `book`).
- В `sections` можно использовать `paragraphs`, `list`, `terms`,
  `example` и `tip` — шаблон сам отрисует нужный блок.

## Где менять дизайн

- Цвета, шрифты и отступы — переменные в начале `static/css/style.css`.
  Заголовки — Golos Text, основной текст — Manrope (файлы лежат в `static/fonts/`).
- Тексты главной — `templates/index.html`.
- Логика интерфейса — `static/js/main.js`.

## Важно для реального запуска

- Замените `app.secret_key` на свой секрет через переменную окружения `SECRET_KEY`.
- Поставьте `debug=False` в конце `app.py`.
- Для боевого сервера используйте WSGI-сервер (например, Gunicorn) и
  не храните подписки в текстовом файле — подключите базу данных.
- Сейчас email сохраняются в `data/subscribers.txt`. Это учебный пример.
